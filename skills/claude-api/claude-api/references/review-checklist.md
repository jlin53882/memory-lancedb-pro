# Claude Code Review Checklist（強化版）

每次使用 Claude Code 進行 code review 時，請確認以下重點：

---

## 1. Schema 對應實作

- 新增的 Schema 欄位是否有對應的實作？
- 程式碼是否正確讀取新欄位？
- 是否有遺漏的欄位需要處理？

## 2. Pattern 邊界條件

- Pattern matching 函式是否有邊界條件測試？
- 空值、極端值的處理是否正確？
- 是否有未處理的 edge cases？

## 3. 常數清理

- 是否有被取代但遺留的常數/函式定義？
- 舊程式碼是否已被移除？
- 是否有重複的程式碼可以合併？

## 4. 改動範圍

- 變更是否只涵蓋需要修改的範圍？
- 無關程式碼是否不受影響？
- 是否有範圍蔓延（scope creep）？

## 5. Error Logging

- 錯誤處理是否完整？
- 是否需要新增 logging？
- 錯誤訊息是否足夠清晰？

## 6. 向後相容

- 變更是否影響現有功能？
- 是否有破壞性變更未告知？
- API/介面是否保持向後相容？

---

## 快速檢查清單

```
□ Schema 新增欄位 → 確認有對應實作讀取
□ Pattern matching 函式 → 提供邊界條件測試
□ 常數/函式定義 → 確認沒有被取代後遺留
□ 改動範圍 → 只涵蓋需要修改的範圍，無關程式碼不受影響
□ Error logging → 確認錯誤處理完整
□ 向後相容 → 確認沒有破壞性變更
```

---
