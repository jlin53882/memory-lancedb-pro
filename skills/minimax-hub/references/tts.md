# 語音合成（Text-to-Speech）

> 使用 `tts` tool 呼叫 MiniMax speech-2.8-hd / speech-2.8-turbo 模型。

---

## 支援模型

| 模型 | 說明 | 語言數量 |
|------|------|---------|
| **speech-2.8-hd** | 最高品質 | 40+ |
| **speech-2.8-turbo** | 低延遲 | 40+ |
| speech-2.6-hd | 高相似度 | - |
| speech-2.6-turbo | 性價比高 | - |

---

## 基本用法

```javascript
tts(text="你好，這是語音測試。")
```

### 指定頻道（影響輸出格式）

```javascript
tts(text="語音內容", channel="telegram")
```

---

## 可用語音（Voices）

> 詳細音色列表請參考 MiniMax 官方文檔。

### 中文音色

| 音色 ID | 說明 |
|---------|------|
| female-tianmei | 中文女聲（預設） |
| male-qn-qingse | 中文男聲（青年） |
| male-qn-jianbin | 中文男聲（簡彬） |

### 英文音色

| 音色 ID | 說明 |
|---------|------|
| English_expressive_narrator | 英文富有表現力的旁白 |

---

## 參數說明

| 參數 | 必填 | 說明 | 預設值 |
|------|------|------|--------|
| `text` | ✅ | 要轉語音的文字 | - |
| `channel` | | 輸出頻道（影響格式） | - |

---

## 輸出說明

`tool` 會自動下載音頻並回傳本地檔案路徑。
回傳格式包含：
- `path`: 本地檔案路徑
- `url`: 原始 URL（如有的話）
- `duration_hint`: 時長提示

---

## 使用場景

| 場景 | 建議 |
|------|------|
| 語音訊息 | 使用 female-tianmei，自然對話 |
| 旁白/解說 | 使用 English_expressive_narrator |
| 男聲語音 | 使用 male-qn-qingse |
| 長文本朗讀 | 注意時長限制，分段處理 |

---

## 速度調整

目前 `tts` tool 預設速度為 1.0（正常速度）。
如需調整，可透過 prompt 說明「請用較慢/較快的速度朗讀」。

---

## 支援語言

speech-2.8-hd 支援 40+ 語言，包括：
- 中文（簡體/繁體）
- 英文
- 日文
- 韓文
- 法文
- 德文
- 西班牙文
- 等等

---

## 限制與用量

- 依 API 用量計費（無固定每日配額）
- 長文本建議分段處理
- 音頻 URL 有效期有限，及時下載

---

## 實用技巧

1. **標點符號**：加入適當的停頓（逗號、句號）讓語音更自然
2. **數字**：數字可以讀出來也可以寫成阿拉伯數字
3. **專有名詞**：確認模型能正確發音
4. **情緒**：可以在文字中加入情緒指示（如「興奮地說」）
