## 生怪磚（Spawner）

### 調查結果：✅ 「生怪磚」是正確的台灣譯名

### 證據

1. **Wiki 繁中版直接使用「生怪磚」**
   - zh.minecraft.wiki `?variant=zh-tw` 的條目名即為「生怪磚」
   - URL：`https://zh.minecraft.wiki/w/刷怪笼?variant=zh-tw`（條目內容已全部使用「生怪磚」）
   - 相關條目：試煉生怪磚、教學:生怪磚陷阱、教學:生怪塔

2. **zh-hant 簡→繁轉換表確認**
   - 來源：`minecraft-zh.gamepedia.com/Minecraft_Wiki:沙盒/Conversiontable/zh-hant?variant=zh-tw`
   - 轉換規則明確記載：`刷怪笼=>生怪磚`
   - 這表示中國大陸簡體用「刷怪笼」，台灣/港澳繁體應譯為「生怪磚」

3. **Bilibili（中國大陸主要平台）使用「生怪砖」**
   - 多個影片標題如「生怪砖版！...骷髅弓箭手农场」確認簡體用法為「生怪砖」
   - 台灣轉換後應為「生怪磚」

## 飽食度（Saturation）

### 調查結果：✅ 「飽食度」是正確的台灣譯名

### 證據

1. **zh.minecraft.wiki（zh-hant 與 zh-tw）皆使用「飽食度」**
   - 飢餓條目（`?variant=zh-tw`）說明：*「飽食度（Saturation）：隱藏數值，耗盡時飢餓條會不時顫抖。」*
   - 飢餓管理教學（`?variant=zh-tw`）：*「飽食度（Saturation）：隱藏數值，耗盡時飢餓條會不時顫抖...」*
   - 飽食效果條目（`?variant=zh-tw`）標題即為「飽食」

2. **minecraft.fandom.com zh-tw variant 使用「飽食度」**
   - 飢餓頁面說明：*「...先補充的是飢餓值，飢餓值的提高也允許了飽食度上限的提高...」*

3. **中國大陸（zh-hans）使用「饱和度」**
   - minecraft.fandom.com 無 variant（預設 zh）頁面：使用「饱和度」一詞
   - mcmod.cn 說明：*「饱和度表示玩家目前的饱和度等级...」*

## 根本問題診斷

### 核心發現

**所有 replace_rules.json 中的 `from` 欄位皆使用繁體中文（zh-tw），而非簡體中文（zh-hans）。**

- `{"from": "刷怪籠", ...}` — 繁體
- `{"from": "試煉刷怪籠", ...}` — 繁體
- `{"from": "刷怪籠礦車", ...}` — 繁體
- `{"from": "飽和", ...}` — 繁體
- `{"from": "生怪蛋", ...}` — 繁體（多處可見）

### 潛在風險

若翻譯流程的 **input 源頭是中國大陸簡體中文**（zh-hans，「刷怪笼」「饱和度」），則：
- 簡體「刷怪笼」→ Rule 1092 的 `from: "刷怪籠"` **不會匹配**→ 「刷怪笼」會殘留在輸出中
- 簡體「饱和度」→ Rule 1315 的 `from: "飽和"` **不會匹配**→ 「饱和度」會殘留在輸出中

### 建議行動

1. **確認 input source 語言**：檢視翻譯 pipeline 中 zh-hans → zh-tw 的轉換起點是什麼語言
2. **若 source 為 zh-hans 簡體**：補入對應的簡體 `from` 規則（如 `{"from": "刷怪笼", "to": "生怪磚"}`）
3. **若 source 已是繁體**：則 Rule 1092、1315 皆為**正確覆寫**，無需修改方向，但可確認現有繁體譯文中是否仍殘留「刷怪籠」或「飽和」（表示歷史翻譯品質問題）

## 規則抽查其餘發現

`replace_rules.json` 共 1325 條規則，全部 `from` 欄位均使用繁體字符（無簡體專用字符如「笼」「砖」「饱」）。

含有「籠」的規則共 3 條（541、725、1092），含有「飽」的規則共 1 條（1315）。

規則中大量使用「生怪蛋」（如 Rule 74、96、105...），此為台灣對 Spawn Egg 的慣用譯名，方向皆為正確。
