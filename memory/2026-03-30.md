## LanceDB `Index.fts()` API 陷阱（重要發現）

### 問題
memory-lancedb-pro 的 FTS index 建立時，`Index.fts()` 傳入 boolean 無效，需傳 options object。

### 錯誤寫法
```typescript
config: (lancedb as any).Index.fts(true)  // ← 錯誤：options = true，withPosition = undefined
```

### 正確寫法
```typescript
config: (lancedb as any).Index.fts({ withPosition: true })  // ← 正確
```

### 根因
`@lancedb/lancedb` 的 `indices.js` 定義：
```typescript
static fts(options) {
    return new Index(native_1.Index.fts(
        options?.withPosition,  // ← options 是 object 才有 .withPosition
        ...
    ));
}
```

### 受影響套件
- `memory-lancedb-pro@1.1.0-beta.10`（實際執行版本）
- `memory-lancedb-pro@1.0.32`（舊版）
- LanceDB 版本：0.26.2
