# PR #2：快速跳轉面板

## 1. 概述

在 NavigationRail 上增加搜尋功能，讓使用者可以快速跳轉到目標頁面。

## 2. 設計目標

- 點擊 NavigationRail 頂部搜尋圖標展開面板
- 支援模糊搜尋頁面名稱
- 顯示鍵盤快捷鍵提示
