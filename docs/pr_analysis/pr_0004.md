## Summary

Implements Phase 2 and Phase 3 from Issue #445 (AliceLJY reviewer feedback) - Proposal A: Dynamic Importance.

### Phase 2: Importance Boost for Used Memories

When a recalled memory is actually used in the response, boost importance by importanceBoostPerUse (default: +0.05).

- Detected via ^Ggent_end hook after message processing
- Applies to all recalled memories (simplified heuristic)

### Phase 3: Importance Penalty for Unused Memories (with min_recall_count guard)

When a memory is recalled but not used in the response, apply penalty by importancePenaltyPerMiss (default: -0.03).

**Protected by minRecallCountForPenalty guard**:
- Only penalizes memories that have been recalled at least minRecallCountForPenalty times (default: 2)
- This prevents new memories from being penalized before they've been given a fair chance to be used
- Checks injected_count from memory metadata before applying penalty

### Configuration

Added config.feedbackSignal to PluginConfig interface:

`	ypescript
feedbackSignal?: {
  /** Boost per successful use (default: 0.05) */
  importanceBoostPerUse?: number;
  /** Boost per user confirmation (default: 0.15) */
  importanceBoostPerConfirmation?: number;
  /** Penalty per miss (default: 0.03) */
  importancePenaltyPerMiss?: number;
  /** Minimum recall count before applying penalty (default: 2) */
  minRecallCountForPenalty?: number;
};
`
