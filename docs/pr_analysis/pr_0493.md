#### Code review findings

1. **`isRecallUsed` duplicate entry** — `"记得"` appears twice in the `usageMarkers` array (lines 377-378 of reflection-slices.ts). Minor, but should be deduplicated.

2. **`bad_recall_count` not incremented on miss** — In the non-used branch, `bad_recall_count` is read as `badCount` but written back as-is (`{ bad_recall_count: badCount }`). It should be `badCount + 1` for the counter to actually accumulate consecutive misses. Currently the penalty path checking `badCount >= 2` will never trigger because the count never grows. Worth verifying this is intentional or a bug.

5. **Recency double-boost guard (Bug 7)** — Skipping `applyRecencyBoost` when `decayEngine` is active is correct since `applyDecayBoost` already incorporates recency.

6. **`source` parameter propagated to `hybridRetrieval`** — Good fix, was previously missing.

7. **Tests** — No new tests for the feedback hooks in this PR. The `isRecallUsed` function is pure and testable; consider adding unit tests in a follow-up.
