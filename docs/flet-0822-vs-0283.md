# Flet 0.82.2 vs 0.28.3 版本差異

> 本文件由實際測試驗證（`0.82.2` 環境），盡量對照 `0.28.3` 的寫法。
> 適用版本：flet 0.82.2（`two_project` 現用版本）

---

## 1. Dialog（對話框）

### 1.1 開啟對話框

| 版本 | API | 範例 |
|------|------|------|
| 0.28.3 | `page.open(dlg)` | `page.open(ft.AlertDialog(...))` |
| **0.82.2** | `page.show_dialog(dlg)` | `self.page.show_dialog(dlg)` |

### 1.2 關閉對話框

| 版本 | API | 範例 |
|------|------|------|
| 0.28.3 | `page.close()` | `page.close()` |
| **0.82.2** | `page.pop_dialog()` | `self.page.pop_dialog()`（不吃參數） |

### ⚠️ 常見錯誤
```python
# ❌ 0.82.2 不存在這些
page.open(dlg)
page.close()

# ✅ 0.82.2 正確寫法
page.show_dialog(dlg)
page.pop_dialog()
```

## 2. Container scroll

### 2.1 滾動屬性

| 版本 | 寫法 | 說明 |
|------|------|------|
| 0.28.3 | `ft.Container(scroll=ft.ScrollMode.AUTO, ...)` | Container 直接支援 scroll 參數 |
| **0.82.2** | 需用 `ft.Column(scroll=ft.ScrollMode.AUTO)` 或 `ft.ListView` | **Container 沒有 scroll 參數** |

### ✅ 正確寫法（0.82.2）
```python
# ❌ 錯誤：Container 沒有 scroll 參數
ft.Container(height=300, scroll=ft.ScrollMode.AUTO, content=...)

# ✅ 正確：滾動設在內層 Column 上
ft.Container(
    height=300,
    content=ft.Column([...], scroll=ft.ScrollMode.AUTO)
)
```

## 3. 廢棄 API（Deprecated）—— 全部有 Warning

> 以下 API 在 0.82.2 仍可運作，但已有 DeprecationWarning，將在 0.83/1.0 移除。

### 3.1 ElevatedButton

| 版本 | 寫法 |
|------|------|
| 0.28.3 / 舊 | `ft.ElevatedButton("文字", icon=..., on_click=...)` |
| **0.82.2** | `ft.Button("文字", icon=..., on_click=...)` |

### 3.2 Border / Padding / BorderRadius（模組函式）

| 廢棄（0.82.2 warning） | 正確（0.82.2） |
|------------------------|----------------|
| `ft.border.all(1, "#000")` | `ft.Border.all(1, "#000")` |
| `ft.padding.symmetric(horizontal=10, vertical=10)` | `ft.Padding.symmetric(horizontal=10, vertical=10)` |
| `ft.padding.only(left=8, top=8)` | `ft.Padding.only(left=8, top=8)` |
| `ft.border_radius.only(5, 5, 5, 5)` | `ft.BorderRadius.only(5, 5, 5, 5)` |

### ⚠️ 特別注意
`ft.border` / `ft.padding` / `ft.border_radius` 現在仍是 **module**（可存取），但內部的 `all()`、`only()`、`symmetric()` 已經 DeprecationWarning。**同時保留兩種寫法**（`ft.border.all()` 和 `ft.Border.all()`）都能執行，但建議用 Class method 版本。

## 4. 完全移除的 API（0.82.2 會炸錯）

### 4.1 TextField `prefix_text`

| 版本 | 寫法 |
|------|------|
| 0.28.3 | `ft.TextField(prefix_text="$ ", ...)` |
| **0.82.2** | 移除。改用 `prefix_icon` 或自己包裝 Row |

### ✅ 替代方案
```python
# ❌ 錯誤（TypeError）
ft.TextField(prefix_text="$ ", ...)

# ✅ 替代：自己用 Row 包
ft.TextField(
    suffix=ft.Text("$ ", color=TEXT_MUTED),
    ...
)
```

### 4.2 Dropdown `on_change`

| 版本 | 寫法 |
|------|------|
| 0.28.3 | `ft.Dropdown(..., on_change=lambda e: ...)` |
| **0.82.2** | `on_change` 移除，改用 `on_select` |

### ✅ 正確寫法（0.82.2）
```python
# ❌ 錯誤（TypeError: unexpected keyword argument 'on_change'）
ft.Dropdown(options=[...], on_change=lambda e: ...)

# ✅ 正確
ft.Dropdown(options=[...], on_select=lambda e: self._on_selected(e))

def _on_selected(self, e):
    value = e.control.value   # 取值方式同 on_change
```

## 5. FilePicker（0.82.2 新用法）

### 5.1 `on_result` 不在 Constructor

| 版本 | 寫法 |
|------|------|
| 0.28.3 | `ft.FilePicker(on_result=self._on_result)` |
| **0.82.2** | constructor 不吃 `on_result`，需屬性賦值 |

### ✅ 正確寫法（0.82.2）
```python
def _ensure_file_picker(self):
    if not hasattr(self, "_file_picker") or self._file_picker is None:
        self._file_picker = ft.FilePicker()
        self._file_picker.on_result = self._on_pick_result
        self.page.overlay.append(self._file_picker)

def _on_pick_result(self, e):
    # e.files 是上傳的檔案列表
    if getattr(e, "files", None):
        paths = [f.path for f in e.files]

# 按鈕 on_click 直接呼叫（不需要 await）
ft.Button("選擇圖片", on_click=lambda _: self._file_picker.pick_files(
    allow_multiple=True,
    allowed_extensions=["jpg", "jpeg", "png", "webp"]
))
```

### ⚠️ `pick_files` 不要 await
`pick_files` 是 async method，但在按鈕 `on_click` 裡面直接呼叫即可，Flet 內部處理。**不需要 `await`**（否則炸 `RuntimeWarning: coroutine was never awaited`）。

## 6. DatePicker

### 6.1 日期選擇事件

| 版本 | 事件 | 取值 |
|------|------|------|
| 0.28.3 | 可能用 `on_change` 或 `on_select` | 視版本而定 |
| **0.82.2** | `on_change` | `e.control.value`（`DatePicker` 實例）或 `self._picker.value` |

### ✅ 正確寫法（0.82.2）
```python
self.date_in = ft.TextField(
    label="日期",
    value=date.today().strftime("%Y-%m-%d"),
    read_only=True,  # 不可打字，只能日曆選
)

self._date_picker = ft.DatePicker()
self._date_picker.on_change = lambda e: self._on_date_selected(e)
self.page.overlay.append(self._date_picker)

# 點擊 TextField 時觸發日曆
self.date_in.on_focus = lambda _: self._date_picker.pick_date()

def _on_date_selected(self, e):
    d = self._date_picker.value  # datetime.date 物件
    if d:
        self.date_in.value = d.strftime("%Y-%m-%d")
        self.update()
```

### 📌 `DatePicker` 在 0.82.2 的重要屬性
- `on_change`：日期變更時觸發（constructor 可接受）
- `value`：目前選中的 `datetime.date`（非 `selected_date`）
- `modal=True/False`：是否為 modal 覆蓋

## 7. 其他 UI 微差異

### 7.1 Chip `selected_color`

| 版本 | 狀態 |
|------|------|
| 0.28.3 | `selected_color` 可能存在 |
| **0.82.2** | `selected_color` 仍存在（無 warning），可繼續使用 |

### 7.2 TextField `prefix_icon`

| 版本 | 狀態 |
|------|------|
| 0.28.3 | 存在 |
| **0.82.2** | `prefix_icon` 仍存在，無 warning |

### 7.3 Slider 事件

| 版本 | 事件 |
|------|------|
| 0.28.3 | 只有 `on_change` |
| **0.82.2** | `on_change`（拖動中持續）+ `on_change_end`（釋放後一次） |

```python
# 拖動時即時更新（0.82.2）
ft.Slider(on_change=lambda e: self._update_display())

# 等釋放後才更新
ft.Slider(on_change_end=lambda e: self._update_display())
```

## 9. 遷移检查清單

當你需要把 0.28.3 程式碼遷移到 0.82.2：

- [ ] `page.open()` → `page.show_dialog()`
- [ ] `page.close()` → `page.pop_dialog()`
- [ ] `Container(scroll=...)` → 移除 Container.scroll，改設在內層 Column
- [ ] `ft.ElevatedButton` → `ft.Button`
- [ ] `ft.border.all()` → `ft.Border.all()`
- [ ] `ft.padding.symmetric()` → `ft.Padding.symmetric()`
- [ ] `ft.padding.only()` → `ft.Padding.only()`
- [ ] `ft.border_radius.only()` → `ft.BorderRadius.only()`
- [ ] `TextField(prefix_text=...)` → 移除，改用 Row 包裝
- [ ] `Dropdown(on_change=...)` → `Dropdown(on_select=...)`
- [ ] `FilePicker(on_result=...)` → constructor 後再賦值 `.on_result`
- [ ] DatePicker `selected_date` → `.value`
